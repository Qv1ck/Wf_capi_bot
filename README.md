# Warframe Telegram Bot

Запуск: `npm install`, затем `npm start` с прежними переменными окружения.

## Ротации Цепи Дувири

Расчёт вынесен в `duviri_rotations.js`. Обычная Цепь использует отдельный цикл из 11 недель. Стальной путь с 22 июня 2026 года использует 9 недель, согласно Update 43:
https://www.warframe.com/en/patch-notes/psn/43-0-0

Сброс происходит в понедельник в 00:00 UTC (03:00 Москвы). Девятая ротация: Вектис, Стаг, Баллистика, Дестреза, Обекс. Длина цикла и список оружия находятся в одном модуле; подписи команд используют эту длину.

Проверка без токена и запуска Telegram:

```bash
node test_duviri_rotations.js
```

Пример регрессии: 12 октября 2026 года старый восьминедельный расчёт давал оружейную неделю 1. Исправленный девятинедельный календарь даёт неделю 7; обычная Цепь при этом находится на неделе 5. Берстон и Нами Соло — оружейная неделя 6, 5–12 октября.

Для применения обновления нужно подтянуть изменения из репозитория и перезапустить процесс бота или выполнить redeploy на хостинге. Сам коммит в GitHub не подтверждает обновление работающего процесса.

Это календарный расчёт, а не запрос текущего списка наград у игрового сервера. Если DE снова расширят или переставят ротации, необходимо обновить список и опорную дату в модуле. Обычная Цепь при таком изменении не должна автоматически перенастраиваться вместе со Стальным путём.
